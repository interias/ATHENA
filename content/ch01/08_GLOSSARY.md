# Glossar — Kapitel 1

| Begriff | Arbeitsdefinition in diesem Kapitel | Nicht verwechseln mit |
|---|---|---|
| Äußere Belastung | dokumentierbare Merkmale der tatsächlich absolvierten Aufgabe [S05] | vollständiger innerer Reaktion |
| Innere Beanspruchung | individuelle körperliche und psychische Reaktion auf die Aufgabe; hier als deutsche Arbeitsbezeichnung für internal load [S05] | ausschließlich Trainingsgewicht oder Distanz |
| Akute Reaktion | zeitnahe Reaktion auf eine Belastung [S06] | bereits nachgewiesener langfristiger Anpassung |
| Anpassung | längerfristige Veränderung durch wiederholte Anforderungen, hier zielbezogen betrachtet [S06] | automatisch besserem Ergebnis jeder Einheit |
| Progression | im Kurs: geplante Weiterentwicklung der Trainingsanforderung | Pflicht, in jeder Einheit mehr zu leisten |
| Tagesleistung | beobachtetes Ergebnis bei einer konkreten Aufgabe zu einem bestimmten Zeitpunkt | vollständiger, direkt gemessener langfristiger Leistungsfähigkeit |
| Hypertrophie | Vergrößerung der Muskulatur beziehungsweise der betrachteten Muskelstrukturen [S04] | jeder Verbesserung eines Krafttests |
| Hypothese | überprüfbare mögliche Erklärung | bereits bewiesener Ursache |
| Zuverlässigkeit | Reproduzierbarkeit einer Messung unter wiederholten Bedingungen [S33] | Gewissheit über die Ursache einer Veränderung |
| Fiktives Beispiel | eigens konstruierte Lehrsituation | realen Daten von Stefan oder einer Studie |

Dies sind bewusst kurze Arbeitsdefinitionen. Spätere Kapitel ergänzen Details und Grenzen. Keine lateinischen Begriffe auswendig lernen, bevor klar ist, wofür sie gebraucht werden.
